# Public visual system

Mayday Dispatch uses a typographic, editorial public system rather than
dashboard or intelligence-themed decoration. The primary navigation is Global
Monitor, Analysis, Forecast, Services, and Contact. About, methodology,
topics, series, and broad browse remain secondary footer destinations.

Global Monitor uses a compact chronological rhythm for public reports and
dispatches. Analysis gives longer research and interpretive work more reading
space. Forecast is reserved for public records explicitly classified by a
forecast/trend-analysis type or tag; it does not imply certainty.

The system uses a neutral paper palette, dark masthead, restrained rules, a
serif hierarchy for publication titles, and sans-serif utilities. It avoids
stock espionage imagery, false urgency, simulated classification, decorative
maps, gradients, and marketing copy. The masthead is typographic; a final logo
is intentionally deferred until the system has matured through real content.

Services describes concrete commissioned work. Contact intentionally does not
provide a form until a real delivery mechanism exists.
